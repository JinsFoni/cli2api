### English

- Add Agnes AI (agnes-ai.com) as a provider. Paste an API key from the Agnes platform and route OpenAI-compatible chat through `agnes-2.5-flash`, `agnes-2.5-pro`, and other text models the key can serve; pin with `agnes/<model>` when cross-provider pooling is off.

### 中文

- 新增 Agnes AI（agnes-ai.com）provider。粘贴 Agnes 平台的 API key 即可接入，通过 `agnes-2.5-flash`、`agnes-2.5-pro` 等 key 可用的文本模型转发 OpenAI 兼容对话；关闭跨池路由时可用 `agnes/<模型>` 钉住该 provider。
